# Сайт Елены Шелестовой — дубликат с правками

Статический сайт (HTML + CSS + небольшой JS) на основе контента
`worksystematically.tilda.ws`, со всеми выявленными правками. Без зависимостей
и сборки — открывается двойным кликом по `index.html` или публикуется на любом хостинге.

## Структура

```
index.html                  главная (все секции)
lichnaya-effektivnost.html  услуга «Личная эффективность»
upravlenie-lyudmi.html      услуга «Управление людьми»
sistemnaya-rabota.html      услуга «Системная работа бизнеса»
privacy.html                политика конфиденциальности (152-ФЗ, noindex)
css/styles.css              стили и адаптив
js/main.js                  меню, форма, фиксированная кнопка
img/                        сюда положить фото (elena.jpg) и og-image.jpg
```

## Что нужно заменить перед публикацией (плейсхолдеры)

Поиск по тексту `[` по всем файлам. Основные точки:

- **Цены и длительность** — `index.html`, секция `#prices` (метки `[X ₽]`, `[60–90]`, `[4 встреч]`).
- **Отзывы** — `index.html`, секция `#reviews` (3 карточки).
- **Кейсы** — цифры `[N] часов` и цитаты `[Цитата клиента]` в секции `#cases`.
- **Контакты** — e-mail `hello@example.ru` в `#contacts` и в футере-ссылках.
- **Privacy** — `privacy.html`: ФИО/ИП, ИНН, адрес, e-mail, дата.
- **Домен** — в `index.html` заменить `https://example.ru/` в `<link rel="canonical">` и `og:url/og:image`.
- **Фото** — положить `img/elena.jpg` (≈720×820) и картинку превью `img/og-image.jpg`.
- **Ссылки Telegram** — проверьте `@elena_shelestova_work` и канал `t.me/worksystematically`.

## Форма заявки

Сейчас форма валидируется на клиенте и выводит сообщение об успехе, но **никуда не отправляет**
(см. `js/main.js`, помечено `TODO`). Варианты подключения без сервера:

1. **Formspree / Getform** — заменить `<form>` на `action="https://formspree.io/f/XXXX"` и `method="post"`.
2. **Tilda** — вставить Tilda-форму (она сама шлёт заявки в личный кабинет).
3. **Свой сервер/бот** — в `main.js` отправить `fetch(...)` на ваш эндпоинт.

Согласие на обработку данных (152-ФЗ) уже в форме, ссылка на политику — на месте.

## Как опубликовать (бесплатно)

- **Netlify Drop** — открыть https://app.netlify.com/drop и перетащить папку целиком. Получите URL сразу.
- **GitHub Pages** — залить папку в репозиторий → Settings → Pages → branch `main`, кодер `/root`.
- **Cloudflare Pages / Vercel** — аналогично, перетаскиванием или из репозитория.

Домен: купить `shelestova.ru` (или похожий) и привязать в панели хостинга; заменить
`example.ru` в `canonical`/`og`.

## Перенос в Tilda (если нужно остаться на Tilda)

Структура главной ↔ блоки Tilda (порядок как на странице):

| Секция | Блок Tilda |
|---|---|
| Шапка с меню | Header (меню + кнопка «Записаться») |
| Первый экран | «Обложка» (T050/T0042) + карточка со списком |
| Полоса доверия | «Лента» / текстовый блок на цветном фоне |
| Для кого | «4 колонки» (T015) |
| Услуги | «3 колонки» (T015/T035) со ссылками на подстраницы |
| Обо мне | «2 колонки» текст + фото (T025) |
| Подход (2 взгляда) | «2 колонки»/карточки (T042) |
| Как проходит | «Нумерованный список» (3 шага) |
| Цены | «Тарифы» (T039) |
| Отзывы | «Отзывы» (T035/T050) |
| Кейсы «было→стало» | «2 колонки» + подписи |
| FAQ | «Вопросы» (аккордеон T042) |
| Форма | «Форма» (Tilda-форма + подключённая политика) |
| Контакты | «Контакты»/иконки |
| Подвал | Footer (Tilda-подвал) + ссылки на политику |

Внутренние страницы услуг — шаблон «Личная эффективность»: обложка → «ситуации» (карточки) →
список «что делаем» → блок результата → кросс-ссылки → кнопка.
